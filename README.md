# Command Keyboard

## 中文

本 Minecraft 1.12.2 模组提供 `/keyboardpress <key1> <key2> ...` 命令，使服务端能够向执行命令的玩家客户端发送按键组合，并模拟这些按键的按下与释放。它支持字母、数字、功能键、方向键、修饰键和数字键盘等常用按键，可用于触发按键绑定、组合键或其他客户端操作。

使用方法：使用 Java 8 将项目作为 Gradle 工程导入 IntelliJ IDEA，然后运行 `build` 任务；也可以在项目目录执行 `.\gradlew.bat build`，生成的 JAR 位于 `build/libs`。

## English

This Minecraft 1.12.2 mod provides the `/keyboardpress <key1> <key2> ...` command, allowing the server to send a key combination to the executing player’s client and simulate pressing and releasing those keys. It supports letters, numbers, function keys, arrow keys, modifiers, the numeric keypad, and other common keys for triggering key bindings, key combinations, or other client-side actions.

Usage: import the project into IntelliJ IDEA as a Gradle project with Java 8, then run the `build` task; alternatively, execute `.\gradlew.bat build` in the project directory, and find the generated JAR in `build/libs`.
